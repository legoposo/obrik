# Obrik

Sistema web para gerenciamento de clientes desenvolvido com Laravel.

## Funcionalidades

- Cadastro, edição e exclusão de clientes
- Consulta e busca de registros
- Organização de informações cadastrais
- Geração de relatórios
- Persistência em banco de dados

## Tecnologias

- PHP
- Laravel
- Blade
- MySQL
- HTML/CSS
